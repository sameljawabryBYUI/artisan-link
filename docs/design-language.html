Design direction

Natural dye on undyed cloth

ArtisanLink is a showcase for handmade work from many countries, browsed by an international audience. The palette borrows from a material almost every craft tradition shares: indigo dye. Japanese aizome, Nigerian adire, Indian block prints and Guatemalan textiles all use it. The page itself stays quiet, like undyed cotton, so the crafts and their makers are what people notice.

What the visual language should feel like

Calm, trustworthy, readable in any language. A catalog first, so listings and contact details stay legible and scannable.

What it should avoid

Loud retail styling, discount-store reds and decoration competing with listings. The spec has no images, prices or payments, so type and color carry the whole design.

Color palette

Four families, each with a single job

Indigo is for action, saffron for highlights, neutrals for reading, and madder and moss only for feedback. Token names become Tailwind utilities, for example bg-indigo, text-ink, border-line.

Typography

A display face with character, a body face built for reading

Display · headings, logo, hero
Bricolage Grotesque

A grotesque with ink traps and slightly irregular curves, so headings feel hand-finished without becoming a costume font. Variable weight 400–800 and optical size, so one file covers every heading.

Body · text, forms, buttons, labels
Figtree

A friendly geometric sans with open letterforms and clear numerals. It reads well at small sizes, covers Latin Extended for accented artisan and country names (Oaxaca, Côte d'Ivoire, Đà Nẵng), and has variable weight 300–900.

Both are free Google Fonts loaded with next/font/google, so they are self-hosted at build time with no layout shift. Fallback stack: system-ui, "Segoe UI", sans-serif.

Rules

Bricolage only for Display, H1 and H2, plus the logo. Everything else is Figtree. Body text never below 16px. Keep paragraphs under about 70 characters wide (max-w-prose).

Weights we use

400 regular, 600 semibold (labels, buttons), 650–750 for headings. No light weights: they thin out on low-quality screens.

Spacing & sizing

A 4px grid, using a short list of Tailwind steps

Page container

mx-auto max-w-6xl px-4 sm:px-6 lg:px-8 (1152px max). Forms and the login card use max-w-xl (576px) so lines stay short.

Breakpoints

Tailwind defaults, mobile first: sm 640, md 768, lg 1024, xl 1280. Every page must work at 360px wide.

Vertical rhythm

Sections: py-12 md:py-16. Inside a section: space-y-6 or gap-6. Use flex/grid gap instead of margins on children.

Elevation

Flat by default: borders, not shadows. A soft shadow appears only on ProductCard hover and on menus (shadow-md).

Layout patterns

One app shell, a layout for every route

Every route in our team plan shares the same header and footer. Wireframes use the proposed colors so the balance of each screen is visible. Dashed boxes are content; solid boxes are components. Each caption names the teammate who owns that page.

Header (Daniel)

White surface, bottom border, 64px tall, sticky. Left: ArtisanLink wordmark in Bricolage, indigo. Center/right: "Products" and "Orders". Far right: "Sign in" button, or the GitHub avatar with a menu (My products, Add product, Sign out) when signed in. Collapses to a menu button below md.

Footer (Daniel)

Ink background, white and muted-light text. Three short columns: About ArtisanLink, Explore (Products, Sell your crafts), Team (four member names, course WDD 430). Stacks to one column on mobile.

Shared UI library

Recommendation: Tailwind v4 tokens plus our own small component kit

Use

Tailwind CSS v4, already installed. Define the palette, fonts and radii once with @theme in app/globals.css. Build a small set of components in app/ui/: Button, InputField, Select, Badge, ProductCard, ProductForm, EmptyState.

Skip for now: shadcn/ui

The spec has no modals, tables, date pickers or menus beyond the header. shadcn would add Radix packages and its own token names for a few buttons. If we need a dialog or dropdown later, it can be added on top of these same tokens.

Proposed app/globals.css theme block. Once agreed, every teammate uses these utilities and no hex values in components: 

@import "tailwindcss";

@theme {
  /* Brand */
  --color-indigo: #24427A;
  --color-indigo-dark: #1A3360;
  --color-indigo-tint: #E8EDF6;
  --color-saffron: #E3A62F;
  --color-saffron-tint: #FBEFD3;

  /* Neutrals */
  --color-cotton: #F6F6F3;
  --color-surface: #FFFFFF;
  --color-ink: #1B2433;
  --color-muted: #586274;
  --color-line: #D9DDE4;
  --color-line-strong: #7C8597;

  /* Feedback */
  --color-madder: #A23B32;
  --color-moss: #2E6B4F;

  /* Type (variables set by next/font in app/layout.tsx) */
  --font-display: var(--font-bricolage), system-ui, sans-serif;
  --font-sans: var(--font-figtree), system-ui, "Segoe UI", sans-serif;
}

body { @apply bg-cotton text-ink font-sans antialiased; }

Usage: <h1 className="font-display text-4xl font-bold">, <button className="rounded-lg bg-indigo px-4 h-10 text-white hover:bg-indigo-dark">.
