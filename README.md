# ArtisanLink - Global Local Crafts Showcase

ArtisanLink is a simple web application that allows local artisans from any country to showcase their handmade crafts to a wider audience.

# Why ArtisanLink Exists

Many talented artisans only sell in local markets and never reach buyers outside their community. ArtisanLink gives them a free, simple online showcase so anyone in the world can discover their work, story, and craft.
